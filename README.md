# 🌻 Florecitas Amarillas para Mí Amor

Una página web interactiva y romántica inspirada en las flores amarillas. Cada tarjeta esconde un mensaje de amor que se revela al tocarla, culminando en un hermoso girasol animado que simboliza un sentimiento sincero.

🔗 **Demo en vivo:** [eduardofleitass.github.io/FLORESAMARILLASMELI](https://eduardofleitass.github.io/FLORESAMARILLASMELI/)

---

## ✨ Características

- 💛 **9 tarjetas interactivas** con mensajes de amor ocultos en distintos idiomas
- 🌻 **Girasol animado** en SVG que se dibuja pétalo a pétalo
- 🎵 **Música de fondo** con controles de reproducción/pausa
- 🍂 **Efectos visuales** de pétalos flotantes y confeti dorado
- 📱 **Responsive:** se adapta a celulares, tablets y escritorio
- 🎨 **Diseño cálido** con paleta dorada, tipografías elegantes y sombras suaves

## 🚀 Tecnologías

- **HTML5** semántico
- **CSS3** con animaciones `@keyframes`, `backdrop-filter` y `grid`
- **JavaScript vanilla** para la interacción y la secuencia del girasol
- **SVG** animado para el girasol final
- **Google Fonts:** *Great Vibes*, *Dancing Script* y *Quicksand*

---

## 🎮 Cómo funciona

1. La página muestra una grilla de **9 fotos** cubiertas por un overlay.
2. Al **tocar/click** cada foto, se revela un mensaje de amor en español o inglés.
3. Una barra de progreso indica cuántas tarjetas has descubierto.
4. Al completar las 9, aparece el **girasol final** con una dedicatoria especial y un corazón latiente.
5. Podes **reproducir o pausar** la música desde el botón inferior.
